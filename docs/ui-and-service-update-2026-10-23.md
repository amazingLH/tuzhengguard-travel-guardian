# 会话工作台与服务策略更新

2026-10-23（北京时间）。

- 会话管理移到独立左侧栏，历史以卡片列表展示；支持新建、自动保存、切换恢复、删除、清空。沿用已有浏览器历史键和加密密钥。时间显示为北京时间，卡片附提问数量。
- 桌面默认展开，手机默认收起，可通过侧边开关打开；历史列表仅纵向滚动，避免多列溢出。
- 标题区加入本地 CSS 绘制的旅行机器人、漂浮、眨眼、挥手、轨道和扫描光效。动画遵循系统减少动态效果设置，不产生网络或模型调用，不显示虚构的运行状态。
- 删除页面额度说明。每日每个浏览器 100 次提问、100 次自行上传图片解析，每位匿名访客 100 次实时高德/FlyAI 核验；全站三类服务没有每日次数上限，旧额度环境变量不再生效。
- 上游明确返回欠费或余额不足时，问答显示提醒弹框及聊天提示，图片解析和实时核验显示错误弹框；网络、权限、普通速率限制错误分别处理。欠费回答不缓存，充值后可以再次请求；已发出的失败请求仍保留服务端计数。

验证：180 项自动化测试、2 个离线案例、Ruff 和编译检查通过。欠费错误使用模拟响应覆盖，未消耗真实模型余额。浏览器检查覆盖桌面与 390px 手机宽度、历史恢复和小屏抽屉。历史运行截图仍标注原始日期，不代表本版本的全部云端能力已经重新实测。
